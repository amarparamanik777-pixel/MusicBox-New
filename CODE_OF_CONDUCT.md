# Code of Conduct

Be kind, be patient, and assume good intent. We welcome people of every background and experience level.

- Give feedback about the work, not the person.
- No harassment, insults or discrimination of any kind.
- Respect other people's time: search existing issues before opening a new one.

Maintainers may remove comments or contributions that break these rules.
To report a problem, open an issue marked "conduct" or contact the repository owner.
